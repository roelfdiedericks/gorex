GoRex

A terminal of tabs and split panes whose sessions stay: quit it, open it again, and everything is where you left it.

Download for Windows

Version unknown, Windows 10 and 11 (x64). Installs for you alone, puts gorex on your PATH, and updates itself. The installer is not signed: Windows SmartScreen asks you to confirm it (More info, Run anyway).

What it does

  • Sessions that stay: shells run in a session server of their own, so quitting GoRex leaves them running, and every tab and pane comes back.
  • Your servers too: gorex ssh user@host opens a window on sessions that live on that host. GoRex copies its server there over ssh and reconnects when the link drops.
  • Tabs and split panes, with each pane's program, directory and status in its header.
  • An editor with a file tree, the changes git sees, and a Markdown preview.
  • Built for coding agents: images (Kitty graphics), pasting images into programs that take them, and what agents report they are doing.
  • Native: Go and Ghostty's terminal emulator, no web view.

Updates

GoRex checks for a new version after it starts and once a day, and offers to install it: Check for Updates… in the command palette asks now. What changed in each version is in the changelog.
