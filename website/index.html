GoRex

A terminal with tabs and split panes whose sessions keep running. Quit it, open it again, and everything is where you left it.

What it does

  • Sessions that stay: shells run in a separate session server. When you quit GoRex, they keep running, and every tab and pane comes back when you open it again.
  • Your servers too: gorex ssh user@host opens a window with sessions that run on that host. GoRex copies its server to the host over ssh and reconnects if the connection drops.
  • Tabs and split panes. Each pane's header shows its program, directory and status.
  • An editor with a file tree, a list of your git changes, and a Markdown preview.
  • Built for coding agents: it shows images (Kitty graphics), lets you paste images into programs that accept them, and shows what agents say they are doing.
  • Native: built with Go and Ghostty's terminal emulator. The Markdown and file previews use the system's web view.

Updates

GoRex checks for a new version when it starts and once a day, and offers to install it. To check now, run Check for Updates… from the command palette. The changelog lists what changed in each version.
